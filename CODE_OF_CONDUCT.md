# Code of Conduct

This project serves churches. Treat everyone here the way you would want to be treated in yours.

## Expected

- Be kind and assume good intent.
- Criticise code and ideas, never people.
- Help newcomers; everyone started somewhere.
- Respect privacy: no personal data of church members, yours or anyone else's.

## Not accepted

- Harassment, insults or discrimination of any kind.
- Personal attacks, trolling, or publishing someone else's private information.
- Sexual language or imagery.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests, and block people who break these
rules. To report a problem privately, use the contact on the maintainer's GitHub profile
([@NoahDR](https://github.com/NoahDR)).
